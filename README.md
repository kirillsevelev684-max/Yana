# ✨ Яна Нейронова 8.0

Голосовой ассистент в одном окне. Скачай готовый **`Yana.exe` из вкладки Releases** — и всё, ничего собирать и ставить не нужно.

![build](https://github.com/USER/Yana/actions/workflows/build.yml/badge.svg)

## 🚀 Как получить .exe

1. Залей проект на GitHub: двойной клик по `PUSH_TO_GITHUB.bat` (создай пустой репозиторий и вставь ссылку).
2. Открой вкладку **Actions** — сборка уже идёт сама на Windows в облаке.
3. Через ~10–15 минут забери `Yana.exe` из вкладки **Releases**.
4. Запусти. При первом старте SmartScreen спросит разрешение («неизвестный издатель» — это нормально) → «Подробнее» → «Выполнить».

Каждая заливка в `main` собирает свежий .exe автоматически.

## 💻 Запуск из исходников (для разработки)

```
pip install -r requirements.txt
python Yana.py
```

## 🎙 Что умеет

- **Голос**: «Яна, …» — сразу ответ, имя в любом месте фразы, всегда слушает в фоне.
- **Чат**: текст + озвучка ответов, живые пузырьки.
- **Память**: имя, факты, контекст диалога, антиповторы.
- **Команды**: свои («запомни команду») + 45 системных Windows.
- **Глаза**: «что на экране?», «что за видео?», «следи за экраном», своя папка.
- **Дом**: устройства, свет, яркость голосом. Плюс калькулятор, заметки, таймеры, погода.
- **Люди**: жен/муж/детские голоса, база незнакомцев.

## 📁 Состав

| Файл | Что это |
|---|---|
| `Yana.py` | Вся программа: Главная, Чат, Модули, Настройки |
| `engine/` | Движок: мозг, слух, голос, глаза, память, дом |
| `voice_library/` | Студийный голос Яны (21 фраза, вшивается в .exe) |
| `assets/` | Логотип-Y (PNG + SVG, вшивается в .exe) |
| `.github/workflows/build.yml` | Облачная сборка Yana.exe |
| `PUSH_TO_GITHUB.bat` | Заливка на GitHub в один клик |

Рядом с .exe сами создаются: `commands.json`, `memory.json`, `devices.json`, `notes.json`,
`settings.json`, `programs.json`, `voice_samples/`, `voice_cache/`, `model/`.

## 🔑 Умные ответы (Groq, бесплатно)
1. Получи бесплатный ключ на console.groq.com.
2. Вставь его в Яне: Настройки → Groq-ключ → Сохранить.
Без ключа работают все офлайн-функции: команды, память, голос, дом.
